# integrations.md — external systems shared across services

## Purpose
Catalogs external systems that multiple services depend on.
Service-specific details (individual endpoint URLs, per-service auth scopes) go
in the service's own .ai/context/integrations.md.

## Structure

## Integrations
One subsection per external system: name, purpose, protocol, authentication method,
which services use it, owner/contact, link to documentation.
