# environment.md — runtime environments and configuration

## Purpose
Describes runtime environments (local, staging, production), required
environment variables, secrets locations, and how the system is configured
in each. The agent reads this before any change that touches configuration
or deployment. Answers "how is this thing configured and where does it
run?" Updated when an environment or config surface changes.

## Structure

## Environments
One subsection per environment: purpose, URL/host, deploy mechanism.

## Configuration
Required env vars, where secrets live, default values.
