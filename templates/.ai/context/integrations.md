# integrations.md — external systems this project integrates with

## Purpose
Catalogs all external systems, APIs, and services the project talks to.
For each: purpose, protocol, authentication, owner. The agent consults this
when work touches integration code. Answers "what does this system depend on
externally?" Updated when an integration is added, removed, or changes
meaningfully.

## Structure

## Integrations
One subsection per integration: name, purpose, protocol/endpoint,
authentication method, owner or contact, link to documentation.
