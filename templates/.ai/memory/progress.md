# progress.md — chronological log of completed work

## Purpose
Append-only log of completed tasks and notable changes, with date and short
summary. The agent appends one entry per finished task or significant event.
Answers "what was done and when?" Grows continuously; never rewritten.

## Structure

## Log
One entry per completion, newest first: date, task name, one-line summary,
link to task directory in `tasks/completed/`.
