## Code Review

1. **important** — hooks/git_rails.py `split_refspec` splits a push refspec at the first colon; git splits at the last. `git push origin 'HEAD^{/fix:}:main'` is allowed while git updates refs/heads/main; `':/fix:main'` asks with the wrong reason (push-delete). A commit-message search with a conventional-commit colon silently passes the protected-push rail.
2. **optional** — `branch.<cur>.merge` is not qualified through `full_name`; `push.default=upstream` with merge `heads/main` is allowed while git pushes refs/heads/main (hand-edited config only).
3. **optional** — `git pull --upload-pack=<cmd>` is parsed but never refused, unlike push's program options.
4. **optional** — `git pull --rebase` with `rebase.updateRefs=true` can move a protected local branch inside the rebased range with no ask; the rebase rule handles updateRefs, the pull path does not.
