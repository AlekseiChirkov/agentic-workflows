# ADR-0006: Decisions for Task unknown — A central, cross-project run log written by a helper script and read only by `/retro`

## Status

Accepted

## Date

2026-08-26

## Related Task

- Task: none — telemetry design
- Related files: `rules/run-log.md`, `log-step.sh`, `workflows/retro.md`, `logs/`

## Summary

Orchestrators call `log-step.sh` (`run-start` / `step` / `run-end`); the helper stamps
timestamps and derives durations; lines go to one machine-global JSONL store; `/retro`
aggregates with `jq` and recommends edits to this repository; logging never blocks a run.

## Context

`progress.md` is narrative and `state.md` is resumable state; neither answers "is the
pipeline getting better, and where does it hurt?" across projects. A model-written
duration is a guess.

## Decisions

### Decision 1: Helper-stamped, append-only, central store

**What was decided:**
`$AGENTIC_LOG_ROOT` or `<repo>/logs/runs/`; one JSONL per run plus a digest; agents
never hand-write a line; every helper error exits 0.

**Why:**
Cross-project questions need one store; guessed numbers are worse than none; telemetry
must never change a decision the pipeline would otherwise make.

**Alternatives:**
- Per-project log in `.ai/` — rejected: cannot aggregate across projects.
- Model-written summaries — rejected: durations would be invented.

**Consequences:**
The helper cannot know when a step *actually* finished — it timestamps when it is
*called*. A run that calls it retroactively (4305eda1: twelve steps at 0 s) produces
valid-looking but useless durations. Vocabulary is documented but not enforced by the
helper.

**Related files:**
- `log-step.sh`, `rules/run-log.md → ## Field vocabulary`

### Decision 2: `/retro` is the only reader

**What was decided:**
No workflow reads the log during a run; `/retro` reports findings that name a file and an
edit, never applies them, and labels small denominators.

**Why:**
Prevents the log from steering runs; keeps changes to workflows deliberate.

**Alternatives:**
- Adaptive pipelines reading their own history — rejected: unpredictable behaviour.

**Consequences:**
Improvement is a human loop: retro → spec → task.
